# Agent：切换账户 / 打开截图

## 何时用

- 「切换账户 Steve」「换成账号 xxx」「用账户 正版」
- 「打开截图」「截图文件夹」「截图在哪」

## 步骤

1. **切换账户**：`select_account`，按用户名 / 账户 id /「正版」「离线」匹配；多个匹配时让玩家说具体用户名；成功后工具卡给「去账户管理」。**绝不**把令牌写进卡片或回复。
2. **打开截图**：`open_screenshots`，定位当前版本 `screenshots/`（没有就创建空文件夹）；工具卡展示路径与大约张数，可「打开截图文件夹」。

## 注意

- 中文玩家向文案；不要提 MCBBS。
- 工具结果走完整工具卡。
- 「切换账户」只改当前选中账户，不删除账户、不发起登录。
