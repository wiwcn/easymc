# Agent：切换版本 / 打开日志 / 账户列表

## 何时用

- 「切换版本 1.21.1」「选择版本 Fabric」「换成 xxx」
- 「打开日志」「最新日志」「打开崩溃报告」
- 「账户列表」「我的账号」「有哪些账户」

## 步骤

1. **切换版本**：`select_instance`，按名称 / MC 版本号 / 加载器关键词匹配；多个匹配时让玩家说具体名；成功后工具卡给「去启动页」。
2. **打开日志**：`open_latest_log`，优先 `logs/latest.log`，没有则最新 `crash-reports/*.txt`；工具卡展示路径，可「打开日志位置」或「分析这份日志」。
3. **账户列表**：`list_accounts`，只展示用户名与正版/离线类型，**绝不**把令牌写进卡片；需要管理时点「去账户管理」（侧栏左下账号卡同入口）。

## 注意

- 中文玩家向文案；不要提 MCBBS。
- 工具结果走完整工具卡。
- 「切换版本」只改当前选中，不删除或重装。
