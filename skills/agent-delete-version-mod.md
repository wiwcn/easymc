# Agent：删除版本与模组

## 何时用

- 「删除版本」「删掉这个版本」「卸载版本 xxx」
- 「删除模组」「删掉 sodium」「卸载模组 iris」

## 步骤

1. **删除版本**：确认目标（须说清版本名，或「当前/这个版本」）→ 调用 `delete_instance`（必填 `query`）→ 工具卡提示已删且不可恢复；引导回启动页。
2. **删除模组**：确认关键词能唯一命中 jar → 调用 `delete_mod`（必填 `query`）→ 多命中时请玩家说得更具体；想先留着改用「禁用」。

## 注意

- 玩家向中文；强调「找不回来」。
- 删除版本会清游戏文件夹；删除模组是删文件，不是禁用。
- 不要提 MCBBS；不要技术口吻。
