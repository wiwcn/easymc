# Agent：模组依赖查缺与补全

## 何时用

- 「缺依赖」「依赖缺失」「查依赖」「补依赖」「补全缺失依赖」
- 「这个整合包好像缺依赖，能不能补上」「缺啥模组」「能不能玩」
- 启动报 missing dependency / 模组要求某某库却未安装

## 步骤（必须多步，不要只列模组就结束）

1. **Look**：确认当前版本；可先 `list_installed_mods`，但**不能停在这里**。
2. **Analyze**：调用 `check_mod_deps`，读 `missing_ids` / 冲突摘要。
3. **Act**：
   - 有缺失 → 调用 `fetch_missing_mod_deps`（或请玩家说「补全缺失依赖」）；宿主会从 Modrinth 下载。
   - 有冲突 → 用中文说明冲突双方，危险操作（删/禁用）等玩家确认。
4. **Verify**：补完后再 `check_mod_deps` 一次，对照缺失是否清零。

## 注意

- 玩家向中文；工具卡展示摘要，勿只回「好了。」
- 不要提 MCBBS；不要编造启动器命令。
- 删模组/删版本仍需确认门控。
