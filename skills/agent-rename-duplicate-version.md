# Agent：重命名与复制版本

## 何时用

- 「重命名版本」「改名」「把版本叫 xxx」
- 「复制版本」「复制一份」「拷一份出来试模组」

## 步骤

1. **重命名**：确认目标版本（默认当前）与新显示名 → 调用 `rename_instance`（可带 `query` + 必填 `new_name`）→ 工具卡展示新旧名称。
2. **复制**：确认要复制的版本（默认当前）与可选副本名 → 调用 `duplicate_instance` → 工具卡展示新版本；副本含模组/资源包/光影/配置/数据包，**不含存档**。

## 注意

- 玩家向中文；不要技术口吻。
- 复制不做「另存存档」；需要世界请玩家自行拷 `saves`。
- 改名只改显示名，不改磁盘目录结构以外玩家无需关心的 id。
